\section{Related Work}
\label{sec:related}

Large scale plant identification has been organised around the LifeCLEF evaluation campaigns~\cite{lifeclef2026}. Early systems relied on hand crafted features such as leaf shape descriptors and colour histograms~\cite{goeau2013pl}. Deep convolutional networks then brought substantial gains on single specimen classification~\cite{lee2017deep}, and recent work has shifted to Vision Transformers, which capture long range spatial structure within images~\cite{dosovitskiy2021image}. The 2024 and 2025 editions of PlantCLEF introduced the vegetation plot setting and with it the gap between specimen level training data and plot level test data~\cite{goeau2024plantclef}. The strongest systems in those editions bridged the gap with tiled inference in the style of SAHI slicing, test time augmentation, and ensembling.

Several pretrained vision models are relevant to this work. BioCLIP~\cite{stevens2024bioclip} is a contrastive vision language model trained on TreeOfLife-10M, whose hierarchical taxonomic captions align its feature space with the Linnaean taxonomy; its features outperform ImageNet pretrained features for species identification, particularly among morphologically similar species. DINOv3~\cite{simeoni2025dinov3} is a self supervised Vision Transformer whose features transfer well across domains and exhibit strong spatial correspondence. ConvNeXt-V2~\cite{woo2023convnextv2} pairs a modernised convolutional architecture with masked autoencoder pretraining, retaining the inductive biases of convolutional networks while matching transformer performance. We use all three as frozen feature extractors in the late fusion baseline of Section~\ref{sec:experiments}.

Fully fine tuning a large pretrained model is often counterproductive on noisy, long tailed data: it demands substantial memory, risks catastrophic forgetting of pretraining knowledge, and tends to overfit. A common alternative freezes most of the backbone and adapts only the top transformer blocks, preserving the lower layer features that capture domain general structure while allowing the upper layers to specialise. For a taxonomically aligned model such as BioCLIP this trade off is especially favourable, since the pretraining prior is precisely what makes the model valuable on biological tasks.

Multi label classification predicts a set of labels per input, typically with sigmoid activations and binary cross entropy. Asymmetric Loss~\cite{ridnik2021asymmetric} extends focal loss~\cite{lin2017focal} to this setting by applying separate focusing parameters to positive and negative samples, aggressively down weighting the easy negatives that dominate when there are thousands of classes. Logit adjustment~\cite{menon2021longtail} offers a complementary mechanism, shifting logits by class prior probabilities so that common classes must produce larger margins than rare ones. Our final system applies prior based logit adjustment at inference time.
