\par\bigskip\textbf{Abstract.}
\fi
%
We describe ANU's submission to PlantCLEF 2026, where the task is to
predict every species present in a vegetation-quadrat image. The
central challenge is a domain shift, with training images showing single
plants while test images show dense multi-species plots, compounded by a
long-tailed label distribution. Our system partially fine-tunes
BioCLIP~2.5 ViT-H/14, unfreezing only the last four transformer blocks
to preserve the Tree-of-Life prior, on an enlarged manifest that
combines PlantCLEF~2024 with a research-grade iNaturalist pull
(2.65~million single-plant images, 7{,}806 species) using auxiliary
genus- and family-level heads that regularise the species head. At
inference each quadrat is split into a $4{\times}4$ grid of sixteen
tiles forwarded at $224$ and $336$ pixels, the per-tile softmax
distributions are averaged, class-prior logit adjustment is applied, and
an adaptive probability threshold selects the species set. Our best
public Macro F1 is \textbf{0.41826} (\textbf{0.40283} private). Project
website: \url{https://arm-wision.github.io/}.
