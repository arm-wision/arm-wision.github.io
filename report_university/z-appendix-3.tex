\chapter{Appendix: Explanation on Empty Pages}\label{chap:appendix3}

You might have noticed that sometimes, though not always, this template automatically adds empty pages. 

The reason for this is closely related to the last section (Appendix \ref{chap:appendix2}). It's because this document is configured as \emph{book}. In a book (check it out!), each new chapter starts ``on the right'' (when the book is opened), i.e., on an odd page. 

Hence, when the last chapter ends on an even page, the next one can simply start on the next, odd page. But if it ended on an odd one, an empty page needs tp be added.
