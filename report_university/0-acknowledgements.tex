\noindent\textbf{Declaration on Generative AI.}
During the preparation of this work, the authors used generative AI tools to
assist with code development, debugging, and language editing. All AI assisted
output was validated before it was relied upon. We continuously monitored
training runs and per epoch metrics, using quantitative measures such as the
macro averaged F1 to verify that AI generated code behaved as intended; whenever
a training run, an F1 score, or any related metric deviated from expectation, we
diagnosed the cause before proceeding. We additionally conducted rigorous code
review, manually reviewing all AI assisted code. After using these tools, the
authors reviewed and edited the content as needed and take full responsibility
for the publication's content.
